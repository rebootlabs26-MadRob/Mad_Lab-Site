# ReBoot Lab — Business Website

**Cyberpunk-themed PC Build & Electronics Repair Business Site**

## 🚀 Live Site
Open `index.html` in any browser to view the site locally.

## 📄 Pages
- **index.html** - Home page with hero and services overview
- **services.html** - Detailed service listings and pricing info
- **about.html** - Company story and values
- **contact.html** - Contact information and appointment details

## 🎨 Design Features
- **Pure HTML/CSS** - No frameworks, no dependencies
- **Cyberpunk Neon Theme** - Green (#00ff66), Cyan (#00ffff), Purple (#bf00ff)
- **Animated Circuit Backgrounds** - Subtle grid patterns
- **Floating Particles** - Dynamic visual effects
- **Responsive Design** - Mobile-friendly layouts
- **Glowing Effects** - Text shadows and box shadows for neon aesthetic
- **Smooth Transitions** - Hover effects and animations

## 🔧 Customization
All colors are defined in CSS `:root` variables at the top of each file:
```css
--neon-green: #00ff66;
--neon-cyan: #00ffff;
--neon-purple: #bf00ff;
```

Change these to customize the entire color scheme instantly.

## 📦 Deployment
Upload all 4 HTML files to any web host:
- GitHub Pages
- Netlify
- Vercel
- Any standard web hosting

No build process required - it's pure static HTML!
